## Why
모델 관리는 이미지·오디오 종류를 저장할 수 있지만 discovery 등록은 텍스트로 고정되고, 미디어 모델에는 텍스트/이미지/오디오 토큰별 입력·캐시 입력·출력 가격 편집과 시간당 단가가 없다. 관리자 가격 설정을 실행 시점의 실제 사용량 과금과 일치시킨다.

## What Changes
- 모델 종류별 목록/등록/관리와 별도 가격 설정 화면을 제공한다.
- 기존 텍스트·캐시 가격 컬럼을 유지하고 `media_pricing.token_rates`로 이미지·오디오별 토큰 가격을 저장한다.
- 오디오 초·분·시간 단가, 명시적 과금 기준과 토큰 과금 예약 금액을 편집한다. 이미지 장당/variant 가격과 기존 설정을 보존한다.
- Lumen은 승인 시 가격을 고정하고 실제 공급자 사용량으로 정산한다. 단가/사용량이 불확실하면 임의 추정·재시도하지 않는다.

## Scope
관리자 모델 설정, discovery 종류 힌트, JSON 가격 계약과 Lumen 정산. 신규 공급자/모델 transport, 운영 가격 추정, 릴리스·배포, 기존 사용자 변경은 범위 밖이다.

## Acceptance
이미지 등록·종류 필터·수정, 이미지/오디오/캐시 토큰 가격 재열기, 시간당 가격 저장, 변경한 필드만 PATCH, 현재 텍스트 설정 보존과 실제 가격 계산을 검증한다. 브라우저 확인과 로컬 테스트를 운영/공급자 검증으로 표현하지 않는다.
