# 사용자 인스턴스 호스트 정보 숨김

## 목표

사용자 영역의 인스턴스 상세 기본 정보에서 컴퓨트 호스트명을 노출하지 않는다.

## 범위

- 공용 `InstanceDetailPanel`의 기본 정보 섹션이 명시적으로 허용된 관리자 컨텍스트에서만 호스트 행을 렌더링한다.
- 관리자 인스턴스·하이퍼바이저·토폴로지 상세 패널은 호스트 행을 계속 표시한다.
- 사용자 인스턴스 목록, 상세 경로, K3s 오버레이, 네트워크 토폴로지 오버레이에서는 호스트 행을 표시하지 않는다.

## 비범위

- API 응답의 `host` 필드와 관리자 외 다른 화면의 호스트 정보는 변경하지 않는다.
- 권한 또는 백엔드 데이터 모델은 변경하지 않는다.

## 완료 기준

- 사용자 컨텍스트의 `InfoSection` 렌더링 결과에 `호스트` 라벨과 호스트 값이 없다.
- 세 관리자 호출 지점은 호스트 표시를 명시적으로 활성화한다.
- 관련 컴포넌트 테스트가 두 동작을 검증한다.
