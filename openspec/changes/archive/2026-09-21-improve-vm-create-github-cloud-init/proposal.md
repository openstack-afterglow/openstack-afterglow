# Improve VM create GitHub SSH and cloud-init

## Goal
Improve VM creation by validating GitHub SSH access before provisioning and making cloud-init reuse practical.

## Scope
- Resolve and verify a selected GitHub user has public SSH keys before any VM mutation, then retain user-scoped recent selections.
- Require a verified GitHub profile for the GitHub SSH mode across normal, async, admin, and squashfs creation paths.
- Keep SSH key import generated by managed cloud-init only; never execute repository content.
- Provide built-in cloud-init presets, safe local text-file loading, saved presets, and executed snippet history.

## Constraints
- GitHub API failures deny GitHub SSH creation safely.
- No token or key material is persisted in Nova metadata or user-facing errors.
- Existing keypair flow and cloud-init library API remain compatible.
