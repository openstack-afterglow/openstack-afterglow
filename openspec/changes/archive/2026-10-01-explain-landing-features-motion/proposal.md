## Why

공개 소개 페이지에 추가한 모션 그래픽이 기능을 설명하지 못한다. 2026-10-02 실제 Chromium 녹화(`~/.gstack/projects/afterglow/designs/landing-motion-audit-20261002/before/`)에서 다음이 확인됐다.

- 환경 구성 미리보기: 단계 이름과 그림의 변화가 맞지 않는다(정책 확인 단계에 네트워크 점선만 진해진다). 동작은 25% 투명도의 등각 상자가 차례로 진해지는 것뿐이다.
- 시나리오별 문제: 클러스터 시나리오는 서버 더미 세 개가 서로 겹친다. 공유 데이터 시나리오는 GPU 서버 그림을 그대로 쓴다. 완료 표시 `✓`가 `√`로 렌더링된다.
- 신청→재사용 스토리: 서로 무관한 그림 네 장이 바뀌기만 하고, 스크롤에 따라 그림이 떠오르거나 확대되는 움직임에 의미가 없다.
- 제품 화면 미리보기: 아이콘 그림을 잘라 확대한 것이라 콘솔 화면을 보여주지 못한다(이전 `fit="cover"` 변경으로 생긴 회귀).
- 기능 카드 그림: 글자가 serif와 monospace 대체 글꼴로 그려진다.

## What Changes

- 환경 구성 미리보기를 콘솔 형태의 장면으로 바꾼다. GPU 연구·클러스터 실습·공유 데이터 시나리오마다 요청 → 정책 확인 → 자원 배정 → 재사용의 각 단계가 해당 패널의 실제 변화를 보여준다.
  - 요청: 항목이 하나씩 반영된다.
  - 정책 확인: 쿼터 막대가 요청량만큼 찬다.
  - 자원 배정: GPU VM, 클러스터 노드와 Pod, 공유 공간과 연결이 생긴다.
  - 재사용: 레이어, 템플릿, 스냅샷이 저장된다.
- 아직 진행하지 않은 패널은 흐린 그림 대신 명시적인 대기 상태로 보여준다. 완료 표시는 글자 대신 SVG 아이콘을 쓴다. 시작·일시정지·계속·다시 체험, 시나리오 전환, 화면 밖이나 탭 숨김 시 정지, 모션 감소 시 즉시 완료하는 계약은 유지한다.
- 신청→배정→관측→재사용 스토리를 하나의 연속 장면으로 바꾼다. 프로젝트 경계, 구성원, 환경 카드, 네트워크와 공유 데이터가 단계를 넘어 유지되고, 단계별 상세(요청 항목, 쿼터, 지표·활동 기록, 레이어 분기)가 순서대로 나타난다. 스크롤 위치에 맞춘 이동·확대 효과와 GSAP 의존성은 제거한다. 단계 활성화는 스크롤 위치와 단계 버튼 선택으로 하고, 장면 전환은 기존 motion token 시간으로 한다.
- 제품 화면 미리보기를 프로젝트 개요·클러스터·네트워크 토폴로지의 콘솔 축약 화면으로 바꾼다.
- 기능·워크플로우 그림의 글자를 디자인 글꼴로 렌더링한다.
- 이전 변경에서 지운 공개 페이지 행동 테스트를 문구에 의존하지 않는 형태로 복원한다(건너뛰기 링크 포커스, 모든 콘솔 이동 링크, 브랜드, footer 링크, raster 이미지 부재). 소개 페이지 라벨의 AA 대비 가드도 복원하고, 새 장면에 대한 상태 전이 테스트를 추가한다.

## Capabilities

### New Capabilities

- `landing-feature-explainers`: 공개 소개 페이지의 기능 설명 장면, 즉 환경 구성 미리보기, 연속 수명주기 장면, 콘솔 축약 화면과 그 모션·접근성 계약.

### Modified Capabilities

(없음. 기존 openspec/specs에 공개 소개 페이지 spec이 없다.)

## Impact

Frontend 공개 소개 페이지 컴포넌트(`frontend/src/lib/components/landing/*`)와 테스트, `frontend/package.json`과 lockfile에서의 `gsap` 제거, `DESIGN.md`·`ARCHITECTURE.md`·`CHANGELOG.md`에 한정한다. Backend, 인증, 실제 provisioning, 사이트 설정과 로고 경로는 바꾸지 않는다. 작업 트리에 있는 다른 세션의 변경을 보존한다.
