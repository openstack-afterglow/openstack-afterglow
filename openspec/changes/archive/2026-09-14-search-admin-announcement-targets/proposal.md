## Why

공지 작성 화면의 사용자·프로젝트 대상이 긴 네이티브 선택 목록으로 노출되어 대상을 찾기 어렵다. 사용자 화면에서는 관리자 발송자임을 즉시 구분하기 어렵고, 로그인 직후 미확인 공지가 있어도 헤더 알림 상태가 다음 폴링까지 늦게 표시될 수 있다.

## What Changes

- 공지 작성의 사용자·프로젝트 대상 선택을 이름과 ID로 필터링하는 키보드 접근 가능한 검색형 단일 선택으로 교체한다.
- 사용자 알림함에서 공지 발송자 이름 뒤에 `(관리자)`를 표시한다.
- 인증 사용자 또는 프로젝트 범위가 바뀌면 미읽음 공지 수를 즉시 조회하고, 미읽음이 있으면 헤더 알림 버튼에 작은 빨간 점멸 점을 표시한다.
- 점멸 효과는 reduced-motion 환경에서 정적으로 표시하고, 알림 버튼의 접근성 이름에는 미읽음 개수를 포함한다.

## Capabilities

### New Capabilities

- 관리자 공지 대상 검색·선택
- 관리자 발송자 식별 표시
- 로그인 직후 미읽음 공지 표시

### Modified Capabilities

- 기존 공지 CRUD, 대상 ID payload, 공지 읽음 처리, 60초 미읽음 폴링은 유지한다.

## Impact

- `frontend/src/lib/components/ui`에 재사용 가능한 검색형 단일 선택 프리미티브와 테스트가 추가된다.
- 관리자 공지 작성 화면, 사용자 알림함, root 헤더 알림 상태가 변경된다.
- 백엔드 API·DB schema·권한·배포 경계에는 영향이 없다.
