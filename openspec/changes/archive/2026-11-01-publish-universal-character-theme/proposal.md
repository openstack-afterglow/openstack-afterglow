## Why
The user requests universal theme asset files for every environment, not Lumen-only mockups, and explicitly authorizes updating DESIGN.md around the resulting library.
## What Changes
Create a canonical character-art registry with reusable service/state/environment variants. Generate independent TXT and text-only transparent SVG files, a manifest and filterable paired-theme catalog. Connect AssetGlyph to the registry and document authority, selection, state semantics, accessibility and integration in DESIGN.md and a detailed guide. No backend or real task state changes.
