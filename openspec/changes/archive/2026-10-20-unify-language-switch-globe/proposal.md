# 언어 변경 버튼 지구본 표시 통일

## 목표

모든 언어 변경 진입 버튼에 기존 지구본 아이콘을 표시한다.

## 범위와 제약

- 공통 `frontend/src/lib/i18n/LocaleSelect.svelte`의 compact·labelled 두 형식에 같은 기존 SVG를 사용한다.
- 랜딩, 로그인(SSO 포함), 회원가입, 계정 찾기, 문서, 사용자·관리자 콘솔을 포함한다.
- 문구·언어 목록·쿠키·URL·접근성 이름·focus·키보드 동작과 기존 디자인 토큰은 변경하지 않는다.
- dev 작업 트리만 수정하며 기존 사용자 설정·서비스·인증에는 접근하거나 배포하지 않는다.

## 완료 기준

- 두 형식의 언어 변경 버튼에 장식용 지구본이 하나씩 표시된다.
- 실제 브라우저에서 공개·콘솔 위치, mobile/tablet/desktop 표시와 언어 전환을 확인한다.
- 관련 아키텍처·디자인·현지화 문서와 검증 기록을 갱신하고 change를 archive한다.
