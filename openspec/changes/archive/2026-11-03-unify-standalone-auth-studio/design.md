# Design

Use AuthStudioShell for the only main landmark, operator brand, locale/theme, existing pausable character artwork and footer. The identity side retains the reference's general workspace copy instead of repeating task headings. Wide consent/workspace panels retain actual choices. Use shared auth-flow heading, fields, actions and links. Desktop splits artwork/form, portrait tablet/mobile shrink artwork first, short landscape pairs related fields. Safe internal panel scrolling takes precedence over clipping security copy, all projects, error and approval details. Do not import study state selectors, fake outcomes or demo identity into the application. Existing handlers and owner/request guards remain unchanged.

Standalone auth/account/consent routes must not remount when locale changes. Root layout bypasses its legacy locale-keyed boundary for shellless entry and token-bearing onboarding routes, as it already does for console surfaces. Reactive message calls update in place. This retains consumed username inspection results, created/accepted outcomes, in-memory provider tickets, consent step/selection and password drafts without repeating network operations. Navigation, session fences and explicit invalidation remain unchanged.
