# Standalone authentication studio

## Why
Adopt the user-approved output/afterglow-login gallery across real independent authentication, account and consent pages, not only login/logout.

## What Changes
Extend the existing AuthStudioShell to account and consent forms; migrate signup/recovery/verified registration/invitation/provider callback/workspace selection/MCP and Claude authorization routes. Preserve every real API contract, session fence, expiry, approval and permission state.

## Impact
Frontend composition and responsive styling only. No identity authority, endpoint, schema, dependency, deployment or credential storage changes. Existing translations and primitives remain authoritative.
