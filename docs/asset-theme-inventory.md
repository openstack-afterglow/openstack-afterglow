- `frontend/src/lib/components/account/ProfileImage.svelte`, `chat/ImageStudio.svelte`, `chat/ChatMessage.svelte`, `object-storage/ObjectFileCard.svelte`: 사용자 사진·생성 이미지·첨부 콘텐츠·object thumbnails는 실제 콘텐츠로 보존한다. fallback/로딩 장식만 대상이다.

## 이번 변경 적용 및 검증

공통 AssetGlyph7종, 공통 EmptyState, 개별 볼륨/볼륨 스냅샷/파일스토리지 스냅샷/키페어 빈 화면, root 오류, 랜딩4종이 문자 에셋을 사용한다. 기존 LoadingState/ProgressTrack 소비 경계는 유지하며 소유자가 가진 권한·콜백·번역·CTA를 보존했다. Warm alias는 Afterglow의warm-text/warm-2로 연결하고 실제 progress/status tone은 보존한다. 조사 중 같은 checkout에서 LoadingState/table/characterTicker의 별도 변경이 관측되어 덮어쓰지 않고 최신 source를 별도로 독립 검토했다. table 변형은 제공되지만 기존 표의 모든 호출부가 새 table변형으로 교체된 것은 아니다. 기존 전체화면 초기 대기와 background-refresh 경계도 유지한다.

검증: 관련6파일28테스트 통과. design named target은142통과/1timeout이었고, timeout난 visualDebt4테스트를 단독 실행해 모두 통과했다. 타입 검사 최종 결과는 이번 작업 완료 보고를 따른다. 독립 검토에서 section 문구 잘림/넓은 진행바 길이 문제를 수정하고 최종 source 승인을 받았다. 임시 docs 검증 경로에서 실제 Svelte 컴포넌트의 라이트/다크·375px 모바일을 관찰했고 페이지375px/scroll375px를 확인했다. 임시 경로는 제거했으며 접근 제어는 변경하지 않았다. 캡처는 output/afterglow-loading/preview-shared-assets*.png에 보관한다.
