STATUS STRIP / CHARACTER SIGNALS
진행 중은 문자 회전으로.
앱의 짧은 진행 표시는 문자 회전([ | ] → [ / ] → [ - ] → [ \ ])을 기본으로 씁니다. 동작 줄이기에서는 [ | ]에 멈추므로 끝난 상태 기호와 겹치지 않습니다.


SETTLED STATES / STATIC
[ + ] 처리 완료[ ! ] 요청 실패[ / ] 권한 확인 필요[ - ] 취소됨
끝난 상태는 회전하거나 로딩을 계속하지 않습니다. 앱의 상태 칩도 같은 기호를 씁니다: 성공 [ + ], 실패 [ ! ], 명시적으로 취소된 작업 [ - ], 그 밖의 중립 상태 [ · ], 진행 중은 문자 회전.
